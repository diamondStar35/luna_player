# Luna Player User Guide

This is a sample user guide used to verify Luna Player's documentation build and Help menu integration.

## Getting started

Use **File > Open File** to choose local media, or **File > Open Link** to play a supported web address.

Press **Space** to play or pause. Press **F1** at any time from the main window to open this guide.

## Documentation status

The complete user guide will be added as Luna Player's documentation is written.
